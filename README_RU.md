# FunPay Gifts — сайт-каталог (тестовая версия)

Это отдельный сайт (FastAPI + HTML/CSS/JS), а не Python-плагин Cardinal. Сейчас он безопасно работает в режиме **без продаж**: каталог пуст, пока не подключён доверенный источник данных Portals; оформление персональных лотов ещё не реализовано. Никаких токенов Portals или FunPay для публикации сайта не нужно.

## Публикация через Render

1. Распакуйте ZIP и загрузите **содержимое** папки `funpay_gifts_render_site` в новый **приватный** репозиторий GitHub, сохранив структуру.
2. На https://dashboard.render.com выберите **New → Web Service**, подключите этот репозиторий. Если Render предлагает Blueprint, можно выбрать `render.yaml`.
3. Для Web Service установите: **Runtime** Python; **Root Directory** `storefront`; **Build Command** `pip install -r requirements.txt`; **Start Command** `uvicorn app:app --host 0.0.0.0 --port $PORT`; **Health Check Path** `/healthz`.
4. Выберите доступный план и нажмите Deploy. Дождитесь статуса Live.
5. Откройте `https://<имя>.onrender.com/` и `https://<имя>.onrender.com/healthz`. Последний должен вернуть `{"ok":true,"checkout_ready":false}`.

**Важно:** при использовании `render.yaml` настройки могут подставиться автоматически. Не устанавливайте `GIFTS_CHECKOUT_ENABLED=1`: оформление пока не подключено и API всегда возвращает 503.

## Локальный запуск (необязательно)

```bash
cd storefront
python -m pip install -r requirements.txt
uvicorn app:app --reload
```

Откройте http://127.0.0.1:8000/.

## Что есть и чего нет

- Есть адаптивная витрина, поиск и подсказки, фильтры, сортировка, 24 карточки на странице, корзина, ввод Telegram username, закрытое оформление.
- Нет автоматической загрузки ассортимента Portals, серверной проверки цен в реальном времени, связки с Cardinal, создания лотов и платежей. Эти функции не имитируются.
- Не добавляйте API-токены в GitHub или frontend. Для синхронизации потребуется отдельный защищённый канал от Cardinal/Portals.
- Render free может иметь ограничения на сон и непостоянную файловую систему. Для реального магазина потребуется устойчивое хранилище и защищённая синхронизация.
